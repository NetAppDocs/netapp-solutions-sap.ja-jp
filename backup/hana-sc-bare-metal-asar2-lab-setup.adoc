= このドキュメントで使用したラボのセットアップ
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
下の図は、使用した実験設備の概要を示しています。2つのシングルホスト HANA MDC システムを使用して、さまざまな操作を実証します。HANA システム BM1 はバックアップ、リストア、リカバリ操作を実行するために指定されており、HANA システム QM1 は SAP システムリフレッシュ操作のターゲットシステムとして機能します。HANA システムは 2 台のベアメタルサーバーに導入されており、ストレージ側では 2 台の ASA A30 2 ノードクラスタが使用されています。最初のクラスターは HANA システムのすべてのストレージユニットをホストし、2 番目のクラスターはバックアップレプリケーションのターゲットとして使用されます。
