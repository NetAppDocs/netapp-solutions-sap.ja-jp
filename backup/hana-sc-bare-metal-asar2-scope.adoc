== 本ドキュメントの内容

本書は環境全体を構成するためのステップバイステップのガイドではなく、ベアメタル サーバーを NetApp ASA ストレージ システムに接続した SnapCenter および HANA に特化した詳細に焦点を当てています。

* SAP HANAシステムのセットアップ
* 特定のSnapCenter設定
* SnapCenter のバックアップ、リストア、およびリカバリ操作の詳細
* SnapCenter SAP システム更新操作の詳細


詳細情報および詳細な設定手順については、link:hana-sc-bare-metal-asar2-additional-info.html["その他の情報"]章に記載されているドキュメントを参照してください。
