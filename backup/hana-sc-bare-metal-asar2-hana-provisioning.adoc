[role="lead"]
本章では、このソリューションドキュメントで使用される SAP HANA システム BM1 の具体的なインストールおよび構成について説明します。HANA システム QM1 も同様の方法で導入されました。

その他の一般的な導入情報とベストプラクティスについては、 https://docs.netapp.com/us-en/netapp-solutions-sap/bp/hana-asa-fc-introduction.html["『 SAP HANA on NetApp ASA Systems with Fibre Channel Protocol 』を参照してください"]をご覧ください。

[[hana-host-configuration]]
== HANAホスト構成

ホストを設定する前に、NetApp SAN ホストユーティリティを http://mysupport.netapp.com/["ネットアップサポート"]サイトからダウンロードし、HANA サーバーにインストールする必要があります。ホストユーティリティのドキュメントには、使用する FCP HBA に応じてインストールする必要のある追加ソフトウェアに関する情報が記載されています。

NetApp SANホストユーティリティを使用して、ストレージシステム上でホストマッピングを設定するために必要なホストアダプタのWWPNを取得することもできます。

....
sapcc-hana-tst-02:~ # sanlun fcp show adapter
host20             WWPN:100070b7e40bbadb
host21             WWPN:100070b7e40bbadc
....


[[multipath-configuration]]

. 各サーバーでLinuxのrescan-scsi-bus.sh -aコマンドを実行して、新しいLUNを検出します。
. sanlun lun show コマンドを実行し、必要なすべての LUN が表示されていることを確認してください。出力には、LUN とそれに対応するデバイスファイルに、ホストからストレージコントローラへの 4 つの FC パスがあることが示されています。

                alias   a30-hana-primary-BM1-data-mnt00001

        multipath {
                wwid    3600a098038323537342b596e55666738

                alias   a30-hana-primary-BM1-shared
        }

[[hana-installation]]
=== HANAのインストール

これで、HANAのインストールを実行できます。


NOTE: 上記の設定では、/usr/sap/BM1 ディレクトリは OS ディスク上に保存されます。/usr/sap/BM1 を別のディスクに保存する場合は、ストレージシステムに追加の LUN を設定する必要があります。
